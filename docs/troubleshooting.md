# 故障处理

| 现象 | 处理 |
|---|---|
|找不到文件|检查我的 iPhone 实际目录；找旧快照和备份，不默认初始化|
|保存后校验失败|选刚保存的新文件；保留旧文件，核对后再操作|
|空文件/损坏JSON|保留原文件，重新运行恢复备份入口|
|权限不足|通过系统界面核对权限，不删除数据|
|云文件未下载|手动导出本地副本，程序不会同步|
|不兼容版本|用对应版本，不能自动重置|
|同周多条记录|先备份再人工核对，不自动合并|
|已登记但提醒报错|先查最新状态，再核对提醒权限，避免再次登记|
|入口运行旧版|确认应用内 ColaManager 是新版|
|统计随旅行变化|保持原设备时区规则，历史归属可能变化|
|自动化停在选择器|本版要求交互，不保证锁屏运行|

JSON解析或权限错误可能由系统直接中断，不能完全捕获分类；错误不视为首次安装。
