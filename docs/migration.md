# 迁移

v1 是 records 字典。v2保留旧字段和未知扩展，新增 app_version、created_at、revision。
只支持版本1/2；损坏、缺字段、异常时间拒绝保存，不能猜测修复。
旧 iCloud 数据先手动导出到本地，再选择该文件迁移；新版不遍历 iCloud。
另存v2且保留v1原文件，失败可用原文件回滚；旧程序不能直接读取v2。

恢复选择备份→预览→二次确认→另存→重读。当前损坏文件不需要先解析。
恢复旧备份会回退数据，需核对修改时间和修订号；不能自动合并分支。
保留标记 __COLA_EMPTY__ 不允许出现在源数据中，避免误替换。
原Scriptable组件仅理解v1且依赖 iCloud，不把v2本地快照声明为兼容输入。
