## 完整候选构建

已实现本地选择器适配器、v1迁移、非覆盖新状态快照、保存输出比较及独立选择读回，
恢复预览和双确认、今日统计、关于及旧业务入口。工作流未指定任何云存储位置。
完整候选的 Python 测试和 JavaScript 断言通过；逐项分层见 test_matrix.md。
正式分发使用 dist/v2/，旧 dist 留档不是新版。签名报告随候选包交付，记录输入/输出哈希。
原生测试最初被审批拦截，随后所有者明确授权导入和运行。隔离规则测试 11/11 通过。
首次执行发现 v1 迁移的数字词典值不被 Apple 接受；改为数字动作输出后重新签名、导入并通过。
Python 测试 30/30 通过，包含该回归检查。实际原生输出随包保存为 docs/native-v2-results.json。
本轮不覆盖完整文件选择器写入/恢复 UI。完整 iPhone 尚未验收。
探针已收到用户成功反馈；没有把这一结果扩展为完整业务验收通过。

本地存储策略变更也意味着不保证无人值守周报，以及无法自动发现最新快照；
这些限制已在 README 和发布说明公开说明。未发布至 GitHub 或 RoutineHub。

## 用户实机反馈与诊断版2

用户报告第一版探针显示创建成功，但重新读取及查找时文件不存在。
因此第一版未通过持久化验收；尚不知道是否出现保存位置选择器、实际位置及 iOS 版本。
不能把此现象归因于 iOS 不支持本地文件，也不能当作用户操作错误。
诊断版2增加保存返回值检查、内容比较和独立文件选择校验；采用新的文件名及
快捷指令名，保留旧探针。7 项结构测试再次通过。诊断版2的 iPhone 结果待反馈。
