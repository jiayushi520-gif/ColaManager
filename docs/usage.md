# 使用

保留我要喝可乐、我已经漱口、我已经刷牙、查看本周额度、查看统计报告、查看历史记录、
设置截止时间、导出备份、恢复备份。新增今日状态、关于及菜单内每周报告/截止检查。
每自然周最多一瓶，未按时打卡禁喝下一周；上周待结算时不能提前用新周额度。
打卡关联最近48小时的最新记录，重复被拒绝；迟到可留痕但不撤销处罚。
系统记录打卡声明，不能验证实际刷牙行为。

查看统计无需保存；首次使用和旧版迁移除外。保存后若取消校验，核对是否已有新文件再重试。
饮用状态先保存再创建提醒；提醒报错不等于饮用未保存，应先查看最新状态。
原生按钮小组件保留，个人自动化手动配置。周报及截止检查需选择文件，不能承诺后台运行。
