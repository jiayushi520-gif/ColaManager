# 安装

1. 导出旧数据并保留旧快捷指令副本。
2. 打开交付包 dist/ColaManager-v2.0.0.shortcut，应用内名称保持 ColaManager。
3. 添加同目录中文入口；ColaManager-Test 只测试导入，不证明持久化。
4. 在“我的 iPhone”创建独立 ColaManager 文件夹。
5. 首次运行查看本周额度，确认新建历史；已有数据应选择最新文件或旧v1文件。
6. 保存新状态后重新选取校验；后续使用最新状态。
7. 用独立测试数据完成18项完整验收后再用于正式记录。

用户探针已通过，iOS版本未知，完整版本兼容性待测。无需开启 iCloud Drive。
保存/读取要文件权限；提醒事项要单独授权，通知权限也需要允许。
